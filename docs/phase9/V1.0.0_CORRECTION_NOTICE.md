# RepoLens v1.0.0 — Post-Release Correction Notice

**Issued:** August 31, 2026
**Superseded By:** v1.0.1
**Scope:** Documentation and release evidence corrections only — no functional code changes.

---

## Purpose

This notice documents factual inaccuracies discovered in the v1.0.0 release evidence pack and release notes after the `v1.0.0` tag was published. The immutable `v1.0.0` Git tag is preserved as-is. All corrections are shipped in the `v1.0.1` corrective release.

---

## Corrections

### 1. Role Taxonomy Error

**v1.0.0 Claim (RELEASE_EVIDENCE_PACK.md §2, §8; RELEASE_NOTES_v1.0.0.md §5):**
> Role-based access control (ANONYMOUS, USER, OPERATOR, ADMIN)
> Fine-grained permissions across `ANONYMOUS`, `USER`, `OPERATOR`, and `ADMIN` roles.

**Fact:** The `UserRole` enum in `backend/app/schemas/enums.py` defines exactly two roles: `USER` and `OPERATOR`. There is no `ADMIN` role. `ANONYMOUS` is a runtime access level (unauthenticated requests), not a persisted role enum value.

**Correction:** RBAC covers `ANONYMOUS` (unauthenticated), `USER`, and `OPERATOR` access levels. No `ADMIN` role exists.

---

### 2. Skipped Test Names Fabricated

**v1.0.0 Claim (RELEASE_EVIDENCE_PACK.md §6):**
> 1. `tests/test_live_providers.py::test_live_openai_provider`
> 2. `tests/test_live_providers.py::test_live_anthropic_provider`
> 3. `tests/test_live_providers.py::test_live_gemini_provider`
> 4. `tests/test_live_providers.py::test_live_github_api`
> 5. `tests/test_pgvector_index.py::test_pgvector_similarity_search`

**Fact:** The actual skipped tests in the codebase are:
1. `tests/test_live_providers.py::test_live_gemini_smoke` (skipped when `GEMINI_API_KEY` unset)
2. `tests/test_live_providers.py::test_live_groq_smoke` (skipped when `GROQ_API_KEY` unset)
3. `tests/test_live_providers.py::test_live_nvidia_smoke` (skipped when `NVIDIA_API_KEY` unset)
4. `tests/test_live_providers.py::test_live_huggingface_smoke` (skipped when `HUGGINGFACE_API_KEY` unset)
5. `tests/test_pgvector_index.py::test_pgvector_real_postgres_integration` (skipped when `PGVECTOR_TEST_URL` unset)

There are no OpenAI, Anthropic, or GitHub API live provider tests in the test suite. The v1.0.0 evidence pack listed test names that do not exist in the codebase.

### 3. Known Limitations Referenced Non-Existent Provider Keys

**v1.0.0 Claim (RELEASE_EVIDENCE_PACK.md §18):**
> Live Provider Integration Tests: Require external API credentials (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `GITHUB_TOKEN`)

**Fact:** The actual environment variables that gate live provider tests are `GEMINI_API_KEY`, `GROQ_API_KEY`, `NVIDIA_API_KEY`, `HUGGINGFACE_API_KEY`, and `PGVECTOR_TEST_URL`. There are no tests gated on `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, or `GITHUB_TOKEN`.

---

### 4. Observability Claims Overstated

**v1.0.0 Claim (RELEASE_EVIDENCE_PACK.md §12; RELEASE_NOTES_v1.0.0.md §6):**
> Structured JSON logging, Prometheus-compatible metrics registry

**Fact:**
- **Logging**: The application uses Python's standard `logging` module. No structured JSON log formatter (e.g., `structlog`, `python-json-logger`) is configured. Log output format depends on the deployment environment's log handler configuration.
- **Metrics**: The metrics collector is an in-memory registry. No Prometheus client library (`prometheus_client`) is installed or integrated. The registry is not Prometheus-compatible without additional integration work.

**Correction:** The application uses standard Python logging and an in-memory metrics registry. Neither structured JSON logging nor Prometheus export is built in.
