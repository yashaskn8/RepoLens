## 2. Explicit Non-Goals & Unsupported Boundaries

The following capabilities are deliberately **UNSUPPORTED** and excluded from v1 scope to preserve stability, security, and architectural simplicity:

- ❌ **Autonomous GitHub Merge / Auto-Approve / REQUEST_CHANGES**: RepoLens publishes review comments only.
- ❌ **Private Repository Ingestion**: RepoLens v1 exclusively analyzes public GitHub repositories.
- ❌ **Direct Code Execution / Remote Dynamic Sandboxes**: Submitted repositories are analyzed statically.
- ❌ **Third-Party OAuth / SSO / MFA / Social Logins**: Local Argon2id session authentication is canonical.
- ❌ **Required Heavy Infrastructure**: Redis remains optional; Celery, Kafka, RabbitMQ, Docker Desktop, and Kubernetes are not required.
- ❌ **Multi-Tenant Organization Workspaces / Billing / Subscriptions**: Clean single-user tenant isolation.
